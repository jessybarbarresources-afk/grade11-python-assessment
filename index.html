Mission 1 • Identifiers

Valid & Invalid Identifiers

An identifier is a name for a variable, function, or other object.

student_name = "Maya"\nscore2 = 18\n_total = 5
Remember: Names can contain letters, digits, and underscores; they cannot start with a digit or contain spaces/hyphens. Python keywords such as if cannot be identifiers. Names are case-sensitive.
1. Which is a valid identifier?
2. Why is 9lives invalid?
3. In Python, total and Total are…
4. Which name follows Python rules?
Mission 2 • Comments

Comments & Code Notes

Comments explain code to people. Python ignores comments when running a program.

# Ask the user for a name\nname = input("Name: ") # read text\nprint(name)
Remember: A single-line comment starts with #. Comments can appear on a line by themselves or after a statement.
1. Which symbol starts a Python comment?
2. What happens to a comment when the program runs?
3. In age = 16 # student's age, which part is the comment?
4. Which is the most useful comment?
Mission 3 • Indentation

Indentation Is Structure

Python uses indentation (leading spaces) to show which statements belong to a block.

if score >= 50:\n print("Pass")\nelse:\n print("Try again")
Remember: The colon : introduces a block. Indent the statements inside it consistently, commonly with four spaces.
1. What does indentation show in Python?
2. Which line correctly begins an if block?
3. Which code has correct indentation?
4. Incorrect indentation may cause…
Mission 4 • Input & output

Talk to the User

input() receives text typed by the user. print() displays information.

name = input("Enter your name: ")\nprint("Hello", name)\nage = int(input("Enter age: "))
Remember: input() returns a string. Convert it with int() for whole numbers or float() for decimal numbers when needed.
1. What does input() do?
2. Which function displays output?
3. Which line reads an integer from the user?
4. What is displayed by print("A", "B")?
Mission 5 • Pseudocode

Plan Before You Code

Pseudocode describes an algorithm in clear, structured language without requiring exact programming syntax.

BEGIN\n INPUT number\n IF number MOD 2 = 0 THEN\n OUTPUT "Even"\n ELSE\n OUTPUT "Odd"\n ENDIF\nEND
Remember: Common keywords include START/BEGIN, INPUT/READ, OUTPUT/PRINT, IF, ELSE, and END. Pseudocode conventions can vary; clarity and sequence matter.
1. Why do programmers use pseudocode?
2. Which pseudocode instruction receives a value?
3. Choose the best order for finding the sum of two numbers.
4. Which pseudocode structure represents a decision?
Mission 6 • Operations

Calculate Carefully

Arithmetic operators perform calculations.

7 + 2 # 9\n7 - 2 # 5\n7 * 2 # 14\n7 / 2 # 3.5\n7 // 2 # 3 (floor division)\n7 % 2 # 1 (remainder)\n2 ** 3 # 8 (power)
Remember: * multiplication, / division, // floor division, % remainder, ** exponent. Parentheses can control order.
1. What is 17 % 5?
2. What is 17 // 5?
3. What is 2 ** 4?
4. What is the value of 3 + 4 * 2?
Mission 7 • Comparisons

True or False?

Comparison operators compare values and produce a Boolean result: True or False.

5 == 5 # True (equal)\n5 != 3 # True (not equal)\n4 < 2 # False\n8 >= 8 # True\n3 < 5 < 9 # True
Remember: == checks equality; = assigns a value. Other comparisons: !=, <, >, <=, >=.
1. Which operator checks equality?
2. What is the result of 6 > 4?
3. What is the result of 10 != 10?
4. What is the result of 7 >= 7?
